# 🌐 Tp Integrador - Programación sobre redes

## 📒 Consigna
- [x] 1)​ Realizar un programa de sockets Cliente Servidor concurrente donde el cliente al conectarse debe enviar su nombre de usuario y contraseña.
- [x] 2)​ Este nombre de usuario y contraseña deben validarse en una base de datos. 
- [ ] 2.1) Extra mio: Intentar usar bcript 
- [x] 3)​ Si el usuario o contraseña son incorrectos se debe informar al cliente y cerrar sesión. Si el nombre de usuario y contraseña son validos el servidor tiene que enviar un mensajde bienvenida.
- [x] 4)​ El cliente debe poder chatear con el servidor y viceversa
- [x] 5)​ Cuando el mensaje del cliente esté precedido por una “/” quiere decir que se trata de un comando
- [x] 6)​ Comandos disponibles:
    - [x] a)​ /repos usuario : El programa Servidor debe guardar los datos de sus repositorios del usuario ingresado por el cliente en una tabla llamada repositorios
    - [x] b)​ /followers usuario: El programa Servidor debe guardar los datos de los followers del usuario ingresado por el cliente en una tabla llamada followers
    - [x] c)​ /hora El servidor debe devolver la hora del momento al cliente
    - [x] d)​ /todos “mensaje” : Ese mensaje debe ser enviado  a todos los clientes que estén conectados
    - [x] e)​ /usuarios El servidor debe devolver la lista de todos los usuarios conectados
    - [x] f)​ /adios Se envía un mensaje de despedida y se desconecta.
